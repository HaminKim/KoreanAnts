리앤트(RI&NT) 한국 부동산·가계신용 사이클 분석 모듈
홈페이지 담당 AI 전달용 기획 및 개발 요구사항
작성 기준일: 2026-10-23
상태: 기획 확정 / 데이터 출처·수집 범위 검증 전

============================================================
0. 프로젝트 목적
============================================================
- 2000년 1월부터 최신 공표 시점까지, 한국 지역별 부동산 가격·가계부채·대출환경·연체·경매의 관계를 관찰한다.
- 전국 평균만 보지 않고 17개 시도를 우선 비교하며, 데이터가 허용하면 시군구 단위로 확장한다.
- 핵심 질문: 어느 지역에 신용이 집중되고 있으며, 신용 위축과 부실이 해당 지역 집값·거래에 어떤 순서와 시차로 나타나는가?
- 책 《빚으로 지은 집》에서 착안한 연구 프로젝트이나, 책의 가설을 사실로 전제하지 않는다. 선후관계·인과관계는 별도로 검증한다.
- 목적은 탐색·연구·투자판단 보조이며, 특정 부동산의 매수·매도를 자동 추천하는 기능은 1차 범위에서 제외한다.

============================================================
1. 연구 대상과 공통 기준
============================================================
- 전체 분석 목표 기간: 2000-01 ~ 현재 최신 공표치.
- 개별 지표가 2000년부터 없으면 실제 최초 공표 시점부터 수집하고, 과거 결측치를 0 또는 임의 추정치로 채우지 않는다.
- 지역: 전국 및 17개 시도(서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주).
- 세종시는 출범 이전 수치의 연결을 임의로 하지 않는다. 기타 행정구역 개편도 기준 변화를 기록한다.
- 가능하면 원본 주기는 그대로 저장(월·분기·연)하고, 비교 차트에는 분기별 변환값을 제공한다.
- 가격지수는 해당 분기의 말월 지수, 잔액은 분기 말 잔액, 신규 실행액·거래량·경매 신규 건수는 해당 분기 합계 등 지표별 집계 규칙을 명시한다.
- 지역의 정의(차주 거주지 / 금융기관 소재지 / 담보주택 소재지 / 실제 거래 주택 소재지)를 필수 메타데이터로 보존한다.

2. 데이터 수집 후보 (우선순위: P0 핵심 / P1 보조)
============================================================
[2-A. 부동산 가격·거래]
P0 - 지역별 아파트 매매가격지수 및 MoM, YoY
P0 - 지역별 아파트 매매거래량
P0 - 가격지수의 최근 고점 대비 하락률(Drawdown)
P1 - 지역별 전세가격지수 및 전세/매매가격 비율
P1 - 지역별 미분양 주택 수
데이터 후보: 한국부동산원 R-ONE, 국토교통부 실거래가·주택통계, KB부동산 장기 가격통계.
주의: KB와 한국부동산원 지수를 섞어 하나의 연속 시계열인 것처럼 표시하지 말 것. 기준연도·표본·산식 개편을 기록할 것.

[2-B. 가계부채·레버리지]
P0 - 지역별 가계대출 잔액 및 YoY
P0 - 지역별 주택담보대출 잔액 및 YoY
P0 - 지역별 신규 주담대 취급/실행금액(확보 가능한 단위부터)
P1 - 지역별 차주당 평균 대출액
P1 - 지역별 가계소득 대비 부채 비율(자료 정의·모집단 일치 시)
P1 - 실제 주택 구매 시 LTV(구매 시 대출액/매입가격): 공개 장기 자료 확보 가능성 별도 조사
데이터 후보: 한국은행 ECOS 및 차주별 가계부채 통계, 금융감독원·금융기관 공표자료.
주의: 신규 취급액과 잔액 증감액은 다르다. 지역별 대출이 반드시 해당 지역 주택을 담보로 한 대출은 아닐 수 있다. ‘실제 매입 LTV’를 대출잔액/지역 평균 집값으로 대체해 표시하지 말 것.

[2-C. 대출 승인·공급·수요·금리·정책]
P0 - 은행 대출태도지수(주택담보대출 관련 세부항목 우선)
P0 - 가계 대출수요지수
P0 - 신규 주담대 실행금액 및 대출금리
P0 - 주요 대출정책 이력(LTV·DSR·스트레스 DSR, 규제지역·대출 상한 등): 시행일·대상 지역·조건 기록
P1 - 실제 대출 승인율(승인 건수/신청 건수): 공개 장기 지역별 자료 존재 여부부터 확인
데이터 후보: 한국은행 대출행태서베이/ECOS, 금융위원회, 금융감독원.
주의: 대출태도지수는 실제 승인율이 아니다. 정책변화와 금리·은행 위험관리·수요감소를 구분해 설명할 수 있도록 지표를 분리한다.

[2-D. 연체·경매·금융 부실]
P0 - 지역별 가계대출 연체율
P0 - 지역별 주담대 연체율(가능한 경우)
P0 - 지역별 신규 부동산 경매 신청 건수
P0 - 지역별 경매 진행 건수
P0 - 지역별 경매 낙찰가율
P1 - 지역별 매각률·유찰률
P1 - 주거용/아파트 경매 별도 필터, 주택 수 또는 가구 수 대비 경매 건수
데이터 후보: 한국은행/금융감독원, 대한민국 법원 경매정보·법원통계, 관련 공식 공개자료.
주의: 신규 신청 건수와 진행 건수를 구분한다. 전체 부동산 경매가 모두 주담대 연체에서 발생하는 것은 아니므로 경매 사유/물건 유형을 구분한다. 장기 공표 자료와 자동 수집의 합법적·기술적 가능성을 먼저 점검한다.

[2-E. 지역별 경제·구매력 (분석 통제변수)]
P1 - 지역별 가구소득/가처분소득, 소득 대비 주택가격(PIR)
P1 - 지역별 고용률·실업률, 인구·가구 수 변화
P1 - 주택 인허가·착공·준공·입주 물량 등 공급 지표
데이터 후보: KOSIS, 한국은행, 국토교통부, 한국부동산원.
주의: PIR 등 파생 지표는 분모·분자의 조사대상, 지역, 기간, 단위를 일치시킨 경우에만 제공한다.

3. 리앤트 화면 제안
============================================================
화면 A / 지역별 주택시장: 지도 또는 지역 비교표, 가격지수·MoM·YoY·고점대비 낙폭·거래량.
화면 B / 핵심: 가계부채 VS 집값: 선택 지역의 가계대출/주담대 증가율과 집값 상승률, 동행·1/2/4분기 시차 비교.
화면 C / 신용공급과 부실: 대출태도·대출수요·금리·신규 실행액 → 연체율 → 신규 경매/진행 건수·낙찰가율.
화면 D / 지역 비교: 부채 증가, 가격상승, 소득대비 부담, 연체율, 인구대비 경매를 나란히 보여주는 비교표·산점도.

공통 UI:
- 지역 선택(전국/시도, 추후 시군구), 지표 선택, 기간 선택(전체/최근 10년/5년/1년/직접 지정).
- 단위와 발표주기, 원자료 출처, 마지막 발표일, 실제 데이터 시작일을 명시.
- 데이터가 없는 지역·기간은 '미공표/미확보'로 표시. 지표 간 비교가 불가능하면 경고 표시.
- 정책 변경일·위기 시점은 이벤트 마커로 켜고 끌 수 있도록 설계.
- 금액 수준, 증가율(YoY/QoQ), 가격지수, 거래량 등은 축/단위를 분리해 오해를 줄일 것.

4. 분석 가설 (데이터로 검증할 질문; 결론으로 단정하지 않음)
============================================================
H1. 과거 부채 증가율이 높았던 지역은 이후 가격 상승률도 높았는가?
H2. 레버리지가 높았던 지역은 신용 위축 시 더 큰 집값 하락을 겪었는가?
H3. 은행 대출태도 강화는 실제 신규 대출 감소를 선행하는가?
H4. 연체율 상승이 경매 신규 신청 증가를 선행하는가?
H5. 경매 증가 구간과 주택가격 저점 간에는 어떠한 시차가 존재하는가?
H6. 대출환경 및 거래량 회복이 집값 반등보다 선행하는가?

분석 원칙:
- 동행, 1분기/2분기/4분기 선행 관계 및 상승기·하락기 분리 비교.
- 인과관계 주장 금지. 금리·소득·실업·공급·정책 변화의 영향을 함께 검토.
- 발표 시차를 고려해 당시 실제로 알 수 있었던 데이터만 사용하는 검증을 선호.
- 지역 간 단순 건수 비교에는 인구·가구·주택수 등 규모 차이를 보정.

5. 데이터 구조·구현 권고
============================================================
- 데이터 수집 전 '지표 데이터 사전'부터 작성: 지표 ID, 정의, 단위, 원천기관, 원본 테이블/API 주소,
  이용 조건, 빈도, 지역단위, 지역 기준, 시작일, 종료일, 발표 시차, 개편 이력, 업데이트 방식.
- RAW 원본은 수정 없이 저장하고, CLEAN(단위·지역코드·개편 처리), DERIVED(YoY·QoQ·낙폭·비율 등)로 분리.
- 지역 코드 및 행정구역 이력을 관리. 지표마다 원본 기간과 결측의 사유를 보존.
- API가 없으면 공식 다운로드 파일을 통한 업데이트 방식을 검토. 허가 없이 사이트 스크래핑부터 진행하지 말 것.
- 별도 개발 전 기존 리앤트 사이트의 데이터 저장 방식, API 호출량, 캐시·스케줄러·오류로그 구조를 확인해 통합.
- 업데이트는 기관 발표 주기에 맞춰 실행하며, 수집 실패가 기존 데이터를 덮어쓰지 않도록 검증 및 롤백 장치를 둔다.

6. 추진 순서와 우선 산출물
============================================================
[1단계: 데이터 확보성 조사 - 지금 바로 할 일]
1) 후보 지표별 공식 출처·데이터 시작연도·공표 주기·지역 해상도 확인.
2) API/CSV/XLS 제공 여부, 무료/유료, 인증키·이용약관 확인.
3) 2000년부터 연속 확보 가능한 자료와 중간부터 시작되는 자료를 명확히 분리.
4) 같은 이름의 지표라도 정의가 바뀌는 지점 및 조사·표본 개편 기록.
5) 결과를 '확보 가능 / 일부 가능 / 불확실·대체 필요' 세 등급으로 정리.

[2단계: 최소 기능 구현(MVP)]
- 17개 시도 기준 아파트 가격지수·상승률·거래량.
- 지역별 가계대출·주담대 잔액과 증가율(확인 가능한 시계열).
- 전국 대출태도·대출수요·금리·대출 실행액(확보 가능한 항목).
- 지역별 연체율·경매 건수·낙찰가율(확인 가능한 항목).
- 지역/기간 선택 및 최소한의 비교 차트.

[3단계: 분석 고도화]
- 지역별 소득 대비 부채, PIR, 규모 보정 경매 비율.
- 2000년대, 2008년 금융위기, 2020~2021년, 2022년 이후 등 장기 사이클 연구.
- 시차 분석, 시군구 확대, 자료 허용 시 실제 주택 구입 LTV 분석.

7. 홈페이지 담당 AI에게 요청할 첫 답변 형식
============================================================
코드를 곧바로 작성하기 전에 다음 표부터 제시해 줘:
[지표명 | 공식 데이터 출처(정확한 페이지/API) | 실제 최초 시점 | 최신 시점 | 지역 단위 | 주기 |
 무료/유료 | 수집 방식 | 정의·개편상 주의 | 확보 가능성]

또한 아래를 함께 알려줘:
- 2000년부터 확보 가능한 핵심 데이터가 무엇인지.
- 지역별 가계부채·주담대·실제 매입 LTV 및 대출 승인율에서 가장 큰 데이터 공백이 무엇인지.
- 기존 홈페이지 데이터 구조를 최대한 유지하면서 단계적으로 붙일 수 있는 MVP 범위.
- 확인되지 않은 데이터, 추정치, 지표 간 단위/지역 정의가 다른 부분은 사실처럼 단정하지 말 것.
